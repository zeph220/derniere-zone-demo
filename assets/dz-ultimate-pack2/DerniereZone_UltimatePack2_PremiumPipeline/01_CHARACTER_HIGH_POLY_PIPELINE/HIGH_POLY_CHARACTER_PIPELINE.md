# Pipeline high-poly personnages

## Étape 1 — Proxy
Utiliser les GLB/OBJ fournis comme volume, taille et silhouette.

## Étape 2 — Sculpt
Dans Blender/ZBrush :
- sculpter visage ;
- plis peau ;
- vêtements ;
- coutures ;
- saletés ;
- asymétries.

## Étape 3 — Retopologie
Créer low-poly propre :
- edge loops articulations ;
- visage lisible ;
- mains propres ;
- épaules/coudes/genoux animables.

## Étape 4 — UV
- texel density cohérente ;
- îlots propres ;
- marges ;
- mirroring seulement si volontaire.

## Étape 5 — Baking
Baker :
- normal ;
- AO ;
- curvature ;
- thickness ;
- ID map.

## Étape 6 — Texturing
Substance Painter :
- basecolor ;
- roughness ;
- normal ;
- AO ;
- height ;
- dirt masks ;
- edge wear ;
- wetness.

## Étape 7 — Rig / Skin
- skeleton humanoïde ;
- weights propres ;
- hitboxes ;
- sockets ;
- LOD skeleton.

## Étape 8 — Export
- FBX rigged ;
- GLB preview ;
- textures PNG/TGA ;
- collision mesh ;
- LODs.
