# Intégration narrative moteur

## Systèmes nécessaires
- DialogueManager
- DocumentManager
- CinematicManager
- SubtitleManager
- QuestManager
- FactionManager
- SaveManager

## Events
- OnDocumentRead
- OnDialogueChoice
- OnCinematicStarted
- OnCinematicEnded
- OnSubtitleLine

## Sauvegarde
Sauvegarder :
- documents lus ;
- dialogues déjà joués ;
- choix ;
- flags de cinématiques ;
- fins débloquées ;
- réputation factions.
