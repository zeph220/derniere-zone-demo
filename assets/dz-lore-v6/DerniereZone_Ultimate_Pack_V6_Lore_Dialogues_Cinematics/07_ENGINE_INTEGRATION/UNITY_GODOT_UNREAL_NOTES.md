# Unity / Godot / Unreal

## Unity
- Timeline pour cinématiques ;
- ScriptableObject ou JSON pour dialogues ;
- Addressables pour documents ;
- UI Toolkit ou Canvas pour sous-titres.

## Godot
- AnimationPlayer / AnimationTree ;
- Control nodes pour dialogues ;
- JSON pour data ;
- Signals pour events narratifs.

## Unreal
- Level Sequence ;
- Data Tables ;
- UMG sous-titres ;
- Blueprint interfaces pour choix et flags.
