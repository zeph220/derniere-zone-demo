# QA narrative premium

## Documents
- [ ] chaque document a un ID unique ;
- [ ] chaque document a une catégorie ;
- [ ] le texte est lisible ;
- [ ] le document peut être marqué lu ;
- [ ] sauvegarde/chargement fonctionne.

## Dialogues
- [ ] état correct selon confiance ;
- [ ] choix appliquent conséquence ;
- [ ] dialogue ne se répète pas mal ;
- [ ] barks ne coupent pas les cinématiques.

## Cinématiques
- [ ] timeline joue ;
- [ ] sous-titres synchronisés ;
- [ ] caméra revient au joueur ;
- [ ] skip si long ;
- [ ] events de quête déclenchés.

## Fins
- [ ] choix final enregistré ;
- [ ] bonne fin affichée ;
- [ ] recap cohérent avec choix.
