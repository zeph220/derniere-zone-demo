# Chapitre 04 — Métro

## Objectif principal
traverser sous la ville pour contourner la surface

## Ambiance / météo
humidité lourde, obscurité, bruit métallique

## Lieux clés
- hall d’entrée
- quais
- tunnels
- wagon bloqué
- station noyée

## Quêtes clés
- réactiver le courant local
- contourner les wagons
- utiliser un leurre sonore

## Boss / climax
L’Oracle des Tunnels

## Rythme recommandé
- introduction d’ambiance ;
- exploration ;
- première tension ;
- rencontre humaine ;
- montée de danger ;
- set-piece ;
- climax ;
- retombée narrative.

## À montrer visuellement
- éléments de lore ;
- météo ;
- détails de rue / décor ;
- événements aléatoires ;
- variations de lumière.
