# Événements aléatoires recommandés

- silhouette qui traverse une fenêtre ;
- homme qui court d’un bâtiment à l’autre ;
- radio lointaine ;
- lumière qui s’éteint ;
- sac qui tombe ;
- survivant blessé ;
- pluie qui s’intensifie ;
- véhicule qui déclenche une alarme ;
- groupe d’infectés attiré par un bruit ;
- marchand itinérant rare ;
- exécution silencieuse d’un PNJ par une créature hors-champ ;
- message graffiti révélant une cache.
