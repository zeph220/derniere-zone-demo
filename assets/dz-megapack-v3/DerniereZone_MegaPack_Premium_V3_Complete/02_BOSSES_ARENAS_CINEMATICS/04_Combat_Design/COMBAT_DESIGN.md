# Combat design premium

## Principes
- pattern lisible ;
- télégraphe visuel/sonore ;
- phase claire ;
- utilisation de l’arène ;
- fatigue / recovery windows ;
- récompense du bon placement.

## Boss fight loop
observer > esquiver > punir > déplacer > gérer adds / environnement > phase suivante.

## Types d’attaques à répartir
- mêlée simple ;
- charge ;
- zone ;
- invocation ;
- mobilité ;
- contrôle ;
- pression psychologique.
