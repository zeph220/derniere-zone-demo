# Cinématiques premium — structure

## Intro boss
1. approche du lieu ;
2. silence / son d’ambiance ;
3. détail d’objet ;
4. apparition de silhouette ;
5. révélation partielle ;
6. plan large de l’arène ;
7. attaque ou menace ;
8. reprise contrôle joueur.

## Transition phase 2
- rupture sonore ;
- blessure visible ;
- changement d’arène ou d’état ;
- nouvelle mécanique.

## Fin de combat
- dernier coup ;
- chute ;
- confirmation visuelle ;
- silence ;
- loot / document / accès ;
- ligne de dialogue ou image forte.
