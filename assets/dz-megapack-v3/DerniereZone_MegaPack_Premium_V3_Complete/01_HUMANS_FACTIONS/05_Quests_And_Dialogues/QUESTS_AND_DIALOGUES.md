# Quêtes et dialogues premium

- récupération ;
- escorte courte ;
- défense ;
- choix moral ;
- reconnaissance ;
- craft ;
- négociation entre factions ;
- sauvetage ;

## Dialogues
Prévoir :
- version neutre ;
- version méfiante ;
- version amie ;
- version urgente ;
- version après échec ;
- version après boss ;
- version selon pluie / nuit / pénurie.

## Exemples de branches
- aider un blessé au détriment des ressources ;
- vendre un document à une faction ou le garder ;
- choisir quel marchand protéger ;
- dénoncer ou cacher un survivant contaminé.
