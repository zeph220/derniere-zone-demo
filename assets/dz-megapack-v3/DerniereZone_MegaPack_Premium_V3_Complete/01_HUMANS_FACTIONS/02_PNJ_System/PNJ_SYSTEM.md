# Système PNJ premium

## Types de PNJ
- donneurs de quêtes ;
- survivants ambiants ;
- marchands ;
- compagnons temporaires ;
- passants d’événement ;
- survivants blessés / mourants ;
- survivants hostiles potentiels.

## Ce qu’un bon PNJ doit apporter
- information ;
- ambiance ;
- économie ;
- morale ;
- rencontre ;
- tension ;
- visibilité de l’état du monde.

## Comportements
- idle situés ;
- observation du joueur ;
- réaction aux bruits ;
- réaction à la pluie et au danger ;
- dialogues conditionnels ;
- disponibilité selon l’heure / les quêtes.
