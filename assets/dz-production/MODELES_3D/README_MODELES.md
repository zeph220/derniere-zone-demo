# Modèles 3D inclus

Nombre de modèles générés : 32

Formats :
- GLB : recommandé pour importer rapidement avec matériaux/couleurs simples.
- OBJ : fallback universel, sans garantie de matériaux avancés.

Ces modèles sont des placeholders low-poly destinés au prototype.

## Catégories
- environment : murs, sols, portes, barricades, props de décor.
- characters : ennemis blockout.
- items : objets ramassables et équipements.

## Important
Les modèles d’outils/armes sont des props fictifs non fonctionnels pour jeu vidéo. Ils ne doivent pas servir de référence technique réelle.
