# Dernière Zone — Dossier de production complet

Ce dossier est organisé pour commencer la production du jeu avec une IA de code, Unity/Godot/Blender, ou une équipe.

## Structure

- `TEXTES/` : documents lisibles de game design, bible sonore, quêtes, survie, ennemis, animations, modèles.
- `DATA/` : JSON/CSV utilisables par Codex ou comme base de données gameplay.
- `MAPS/` : cartes ASCII et descriptions de niveaux/bâtiments.
- `MODELES_3D/` : modèles 3D placeholder en GLB et OBJ.
- `ANIMATIONS/` : specs d'animations en JSON, séparées joueur/ennemis/props.
- `BLENDER_SCRIPTS/` : script Blender pour régénérer/adapter des blockouts.
- `CODEX_PROMPTS/` : prompts prêts à copier dans Codex.

## Important

Les modèles 3D inclus sont des **blockouts low-poly** pour prototyper. Ils ne sont pas des assets finaux AAA.
Ils servent à :
- remplacer les cubes ;
- tester les dimensions ;
- avoir des ennemis, objets, murs et props immédiatement ;
- donner une direction claire à Codex/Blender/Unity/Godot.

Les armes présentes sont des **props fictifs de jeu non fonctionnels**, sans détails techniques réels.
