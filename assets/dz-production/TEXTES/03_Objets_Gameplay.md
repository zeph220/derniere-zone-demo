# 03 — Objets de gameplay : utilité, obtention, usage

## Catégories
1. Survie.
2. Soin.
3. Craft.
4. Quête.
5. Équipement.
6. Abri.
7. Troc.

## Objets de survie

### Bouteille d’eau
Utilisation : remonte la soif de 35.
Où la trouver : supérette, appartements, distributeurs, sacs de survivants, abri après récupérateur d’eau.
Animation : main gauche tient bouteille, main droite dévisse, caméra baisse légèrement, son de gorgées.
Notes : peut être vide après usage et devenir une bouteille vide utile au craft.

### Bouteille vide
Utilisation : stocker eau de pluie, craft filtre, troc faible.
Où la trouver : poubelles, supérette, rues, abri.

### Conserve
Utilisation : remonte la faim de 30.
Où la trouver : supérette, dépôt militaire, appartements.
Animation : ouvrir rapidement, manger à la cuillère ou directement, bruit métal.
Risque : certaines conserves peuvent être périmées en difficulté dure.

### Barre énergétique
Utilisation : faim +15, endurance +10 temporaire.
Où la trouver : distributeurs, sacs, supérette.
Usage rapide en combat ou fuite.

### Ration militaire
Utilisation : faim +45, soif -5.
Où la trouver : zone militaire, troc avec factions.
Très utile pour expéditions longues.

## Soins

### Bandage
Utilisation : arrête saignement, vie +10 si pas de saignement.
Où le trouver : pharmacie, hôpital, craft tissu.
Animation : enrouler autour de l’avant-bras, tirer pour serrer, respiration courte.

### Bandage sale
Utilisation : arrête saignement mais risque infection +10.
Où le trouver : rues, ennemis, bâtiments sales.
Peut être stérilisé avec alcool.

### Antiseptique
Utilisation : réduit risque infection, améliore bandage.
Où le trouver : pharmacie, hôpital.
Animation : verser sur plaie, réaction douleur.

### Antibiotique
Utilisation : réduit infection déclarée.
Où le trouver : hôpital, pharmacie verrouillée, quête médecin.
Très rare.

### Kit médical
Utilisation : vie +45, arrête saignement, réduit infection mineure.
Où le trouver : hôpital, ambulance, zone militaire.
Objet précieux, doit rester rare.

### Attelle
Utilisation : soigne entorse/fracture légère.
Craft : bois + tissu + ruban.
Animation : fixer jambe ou bras.

## Craft

### Tissu
Source : vêtements, draps, rideaux, sacs.
Utilisation : bandages, filtres, torches, réparation sac.

### Bois
Source : palettes, meubles, barricades.
Utilisation : abri, barricades, attelle, pièges.

### Métal
Source : garage, voitures, étagères, grilles.
Utilisation : outils, armes de fortune, renforts.

### Câble
Source : boîtiers électriques, garage, labo.
Utilisation : radio, générateur, pièges, portes.

### Pile
Source : tiroirs, radios, lampes, magasin, laboratoire.
Utilisation : lampe torche, radio, appareils.
Animation : ouvrir compartiment, insérer pile.

### Ruban adhésif
Source : garage, bureaux, militaires.
Utilisation : réparation, craft, bandage amélioré.

### Filtre
Source : pharmacie, labo, militaire.
Utilisation : masque à gaz, eau propre.
Craft avancé : tissu + charbon + plastique + filtre usé.

## Équipement

### Lampe torche
Utilisation : éclaire zones sombres, consomme piles.
Où la trouver : garage ou abri.
Risque : lumière attire certains ennemis.

### Sac
Utilisation : augmente capacité.
Versions : petit sac, sac renforcé, sac tactique.
Où le trouver : abri, survivants, école, militaire.

### Pied-de-biche
Utilisation : ouvrir portes simples, caisses, planches.
Où le trouver : garage.
Animation : pousser l’outil dans une fente, forcer, craquement.

### Masque à gaz
Utilisation : entrer zones contaminées.
Où le trouver : zone militaire ou laboratoire.
Nécessite filtres.

### Radio portable
Utilisation : recevoir signaux, objectifs, indices.
Où la trouver : quête principale radio.
Peut déclencher événements.

### Carte d’accès
Utilisation : ouvrir zones laboratoire/militaire.
Où la trouver : quêtes, cadavres, bureaux sécurisés.

## Objets d’abri

### Coffre
Utilisation : stockage permanent.
Améliorations : taille, tri, sécurité.

### Établi
Utilisation : craft outils, réparations, armes de fortune.
Améliorations : établi simple, avancé, électrique.

### Lit
Utilisation : dormir, sauvegarder, réduire fatigue.
Améliorations : matelas, couvertures, isolation.

### Radio fixe
Utilisation : histoire principale, signaux, factions.
Améliorations : pile, câble, antenne, amplificateur.

### Récupérateur d’eau
Utilisation : produit eau brute quand il pleut.
Upgrade : filtre pour eau potable.

### Générateur
Utilisation : électricité de l’abri.
Consomme carburant.
