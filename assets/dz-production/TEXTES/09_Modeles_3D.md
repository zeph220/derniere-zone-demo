# 09 — Modèles 3D nécessaires

## Règle de production
Toujours commencer par un blockout propre, puis améliorer.
Les modèles inclus dans `MODELES_3D` servent de base low-poly, pas de résultat final.

## Personnage / vue FPS
- Bras + mains gantées.
- Variantes : mains sales, gants usés, bandage visible après blessure.
- Les mains doivent être lisibles mais pas trop grosses à l’écran.
- Prévoir points d’attache pour objets : bouteille, bandage, lampe, outil.

## Ennemis
- Ennemi normal.
- Ennemi rapide.
- Ennemi aveugle.
- Ennemi lourd.
- Sujet de laboratoire.

Chaque ennemi doit avoir :
- silhouette différente ;
- matériau peau/vêtement ;
- points visuels lisibles ;
- collider simple ;
- hitbox tête/torse/bras.

## Armes / outils de jeu
Les assets doivent rester fictifs et non techniques.
- Tube métallique.
- Hachette/outillage.
- Couteau utilitaire stylisé.
- Arme courte fictive blockout si nécessaire pour placeholder, sans détails réalistes.
