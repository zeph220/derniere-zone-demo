# Animations

Les fichiers `.anim.json` ne sont pas des animations Unity/Godot directement importables.
Ils décrivent les keyframes, timings, effets gameplay et sons à utiliser.

Utilisation conseillée :
1. Lire le JSON dans Codex.
2. Créer l’animation dans Unity/Godot/Blender.
3. Respecter les timings gameplay.
4. Remplacer ensuite par de vraies animations.
