# Dernière Zone — Audio Pack de départ

Ce pack contient des musiques d'ambiance et des SFX originaux générés pour servir de base/placeholder propre au jeu.

Format :
- WAV 44.1 kHz
- Musiques en stéréo
- SFX majoritairement en mono
- Noms de fichiers propres pour import Unity/Godot

Important :
Ces fichiers sont faits pour prototyper et donner une direction sonore cohérente. Ils ne remplacent pas un sound design final professionnel, mais ils permettent de commencer avec une vraie identité sonore.

Structure :
- /music : boucles musicales et ambiances longues par zone
- /sfx : sons courts de gameplay et ambiances courtes
- /docs : plan d'utilisation, manifest, mapping zones

Conseil :
Dans le jeu, sépare toujours :
1. Music
2. Ambience
3. SFX
4. UI
5. Voices / Enemies

Comme ça tu pourras régler les volumes dans les options.
