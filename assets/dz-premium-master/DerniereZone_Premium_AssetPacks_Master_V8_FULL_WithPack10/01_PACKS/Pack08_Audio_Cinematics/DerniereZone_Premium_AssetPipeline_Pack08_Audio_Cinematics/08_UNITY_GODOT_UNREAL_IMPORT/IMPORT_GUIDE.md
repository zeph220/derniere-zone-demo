# Guide import — Audio / Cinématiques

## Unity
- AudioMixer avec bus Master/Music/Ambience/SFX/UI/Dialogue/Radio/Enemies.
- Timeline pour cinématiques.
- Animator ou UI Toolkit animations pour écrans.
- Script AudioManager piloté par `audio_events.json`.
- Script CinematicManager piloté par timelines JSON.

## Godot 4
- Bus audio dans Audio panel.
- AnimationPlayer pour UI/cinématiques.
- AudioStreamPlayer / AudioStreamPlayer3D.
- Signals pour IA, UI, quêtes.
- JSON pour cinématiques et événements audio.

## Unreal
- Sound Classes / Sound Mixes.
- MetaSounds ou Sound Cues.
- Level Sequences pour cinématiques.
- UMG Widget Animations.
- Data Tables pour timelines.
