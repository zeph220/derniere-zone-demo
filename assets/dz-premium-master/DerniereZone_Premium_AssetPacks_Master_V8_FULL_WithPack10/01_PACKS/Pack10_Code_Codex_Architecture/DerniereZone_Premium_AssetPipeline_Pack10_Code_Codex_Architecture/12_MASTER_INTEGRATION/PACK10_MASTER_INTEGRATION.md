# Pack10 integration

Pack10 ne remplace pas les autres packs. Il explique comment les utiliser dans le code.

## Liens avec packs

- Pack01 Shelter : scènes hub, interactables abri.
- Pack02 Street : scènes rue, prefabs modular street.
- Pack03 FPS Hands : animations d'utilisation et interaction.
- Pack04 Enemies : EnemyAI, data enemies.
- Pack05 UI/HUD : UI screens, widgets.
- Pack06 Props/Items : items.json, crafting_recipes.json, modèles objets.
- Pack07 AdvancedZones : zones.json, level design.
- Pack08 Audio/Cinematics : audio_events.json, timelines.
