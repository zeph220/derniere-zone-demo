# Debug tools

## Debug overlay
Afficher :
- FPS ;
- scène actuelle ;
- quest active ;
- player stats ;
- inventory weight ;
- current interactable ;
- audio state ;
- save status.

## Enemy AI debug
Afficher :
- état ;
- suspicion ;
- last seen ;
- last heard ;
- vision cone ;
- hearing radius ;
- nav path.

## Quest debug
Commandes :
- start quest ;
- advance quest ;
- complete quest ;
- reset quest ;
- show flags.

## Inventory debug
Commandes :
- add item ;
- remove item ;
- clear inventory ;
- fill inventory.

## Save debug
Commandes :
- save now ;
- load slot ;
- delete slot ;
- validate save.
