# DataRegistry

## Rôle
Charge tous les JSON et fournit les données par ID.

## Dépendances
- aucune

## Events
- DataLoaded
- DataLoadFailed

## Règles Codex
- Ne pas mélanger ce système avec un autre.
- Utiliser des IDs data-driven.
- Prévoir sauvegarde si état persistant.
- Prévoir debug logs.
- Prévoir tests simples.
