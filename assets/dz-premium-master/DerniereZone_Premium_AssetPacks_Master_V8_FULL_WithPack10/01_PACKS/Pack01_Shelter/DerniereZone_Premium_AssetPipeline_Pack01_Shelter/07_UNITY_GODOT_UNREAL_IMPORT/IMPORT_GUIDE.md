# Guide import Unity / Godot / Unreal

## Unity
Importer OBJ, créer prefab, assigner matériaux, ajouter colliders simples, ajouter Interactable, placer prompt anchor.

## Godot 4
Importer OBJ, convertir en scène, ajouter StaticBody3D + CollisionShape3D, Area3D pour interaction, StandardMaterial3D.

## Unreal
Convertir idéalement en FBX, créer Material Instances, collision simple, Blueprint Actor interactif, LODs.

## Naming
`DZ_Shelter_[AssetName]_[Variant]`
