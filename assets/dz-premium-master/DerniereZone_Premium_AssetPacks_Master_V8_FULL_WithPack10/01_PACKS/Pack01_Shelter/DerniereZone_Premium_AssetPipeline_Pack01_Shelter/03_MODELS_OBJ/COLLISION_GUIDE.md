# Collision guide

Ne pas utiliser les meshes détaillés comme collision finale.

Collisions recommandées :
- Lit : BoxCollider simple.
- Radio : BoxCollider + Trigger interaction.
- Établi : box principale + prompt anchor.
- Coffre : box + trigger ouverture.
- Générateur : box + zone audio.
- Porte : collision fermée/ouverture.
- Lampe : collision désactivée ou petite capsule.
