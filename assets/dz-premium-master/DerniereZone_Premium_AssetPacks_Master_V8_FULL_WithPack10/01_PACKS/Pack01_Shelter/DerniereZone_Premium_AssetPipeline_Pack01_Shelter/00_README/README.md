# Dernière Zone — Premium Asset Pipeline — Pack 01 : Abri

Ce pack commence le pipeline premium du jeu par l'abri, le hub principal.

Ce n'est pas un asset pack AAA final déjà sculpté/retopo/texturé à la main. C'est une base de production sérieuse pour aller vers ce niveau :
- briefs artiste précis ;
- modèles OBJ plus détaillés que des cubes ;
- textures PBR 2K procédurales ;
- specs d'animations ;
- icônes ;
- règles d'import Unity/Godot/Unreal ;
- checklist qualité type Marketplace ;
- script Blender d'import.

Pour atteindre un vrai niveau Marketplace premium, il faudra ensuite ouvrir ces bases dans Blender/Substance, refaire les UV, ajouter détails high-poly, baker les maps, créer LOD/collisions et tester en moteur.
