# UI Style Guide — Dernière Zone

## Intention
L'interface doit ressembler à un mélange entre :
- carnet de survivant ;
- radio militaire ;
- tablette abîmée ;
- documents papier annotés.

## Palette
- Fond : noir/vert très sombre.
- Texte : beige clair.
- Danger : rouge désaturé.
- Avertissement : orange.
- Succès : vert doux.
- Information : bleu gris.
- Factions : couleur dédiée par groupe.

## Règles
1. L'UI ne doit jamais être plus brillante que le monde.
2. Les écrans doivent rester lisibles sur fond sombre.
3. Les animations doivent être courtes.
4. Les notifications doivent disparaître seules.
5. Les choix moraux doivent afficher un avertissement discret : “conséquence possible”.
6. Les éléments critiques doivent avoir un son.
7. Les documents longs doivent être séparés du gameplay par un écran lisible.

## HUD
Le HUD doit être discret :
- stats en bas gauche ;
- objectif court en haut gauche ;
- interaction au centre bas ;
- menace/danger par son et vignette, pas gros texte ;
- mini notifications à droite.

## Inventaire
Doit montrer :
- poids ;
- catégories ;
- grille d'objets ;
- description ;
- actions ;
- raccourcis ;
- objets de quête non jetables.

## Carte
Style papier mouillé/carte annotée :
- zones découvertes ;
- objectifs ;
- dangers ;
- refuges ;
- marqueurs personnalisés ;
- notes du joueur.

## Dialogues
- Portrait/nom PNJ.
- Texte court.
- Choix limités à 4.
- Indicateurs de ton : empathique, méfiant, hostile, mensonge, compétence.
- Feedback relation si nécessaire.

## Mort
L'écran de mort doit expliquer :
- cause ;
- lieu ;
- temps survécu ;
- astuce ;
- options de reprise.
