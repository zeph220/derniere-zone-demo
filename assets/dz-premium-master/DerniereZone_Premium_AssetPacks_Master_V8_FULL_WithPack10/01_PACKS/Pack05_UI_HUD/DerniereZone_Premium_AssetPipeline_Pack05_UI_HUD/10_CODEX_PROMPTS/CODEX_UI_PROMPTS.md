# Prompts Codex — UI/HUD

## HUD
Lis `screens.json`, `ui_theme.json` et `UI_PREFABS_AND_WIDGETS.md`. Crée un HUD minimal avec vie, faim, soif, endurance, objectif actuel, interaction prompt et notifications.

## Inventaire
Crée l'écran inventaire avec catégories, grille d'items, détails, actions utiliser/transférer/jeter. Les données doivent venir de `items.json`.

## Quest Journal
Crée le journal de quêtes avec catégories principale, secondaires, abri, factions, terminées. Les données doivent venir de `quests.json`.

## Dialogue
Crée une boîte de dialogue avec nom PNJ, texte, 2 à 4 choix, tags de ton et callback de conséquence.

## Save/Load
Crée écran sauvegarde/chargement avec slots, nom de zone, temps de jeu, chapitre, confirmation écrasement.

## Death Screen
Crée écran de mort qui reçoit cause, lieu, temps survécu et astuce contextualisée.
