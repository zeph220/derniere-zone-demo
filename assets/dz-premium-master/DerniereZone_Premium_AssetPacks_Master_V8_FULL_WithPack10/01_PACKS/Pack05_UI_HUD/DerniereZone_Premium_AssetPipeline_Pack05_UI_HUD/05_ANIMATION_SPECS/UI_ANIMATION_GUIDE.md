# Guide animations UI

## Règles
- Animations courtes.
- Pas de mouvement inutile.
- L'UI ne doit pas retarder le gameplay.
- Les écrans critiques peuvent mettre le jeu en pause.
- Les popups ne doivent pas cacher le centre de l'écran.
- Les choix moraux doivent avoir une animation plus lourde et silencieuse.

## Durées recommandées
- Hover : 0.15 à 0.2 s.
- Ouverture inventaire : 0.25 s.
- Popup objectif : 2.5 à 3 s.
- Écran de mort : 1.5 à 2 s.
- Sauvegarde : 1 à 1.5 s.
