# Guide import UI — Unity / Godot / Unreal

## Unity
- Utiliser Canvas en Screen Space Overlay ou Camera.
- Créer prefabs UI par écran.
- Utiliser ScriptableObjects ou JSON pour données.
- Input System pour navigation clavier/manette.
- Animator ou DOTween-like pour transitions.
- Séparer HUD et menus pause.

## Godot 4
- Control nodes.
- CanvasLayer pour HUD.
- Theme resource pour style.
- AnimationPlayer pour transitions.
- JSON resources pour items/quests.
- Signals pour updates.

## Unreal
- UMG Widgets.
- Data Tables pour items/quests.
- CommonUI si disponible.
- Widget animations.
- Input actions pour navigation.
- SaveGame object pour slots.
