# QA UI/HUD

## Lisibilité
- [ ] Lisible en 1920x1080.
- [ ] Lisible en 1366x768.
- [ ] Contraste suffisant.
- [ ] Texte pas coupé.
- [ ] Taille texte réglable.

## Navigation
- [ ] Souris.
- [ ] Clavier.
- [ ] Manette prévue.
- [ ] Retour/annuler fonctionne.
- [ ] Aucun écran ne bloque le joueur sans sortie.

## Gameplay
- [ ] HUD ne cache pas le centre.
- [ ] Inventaire met le jeu en pause si nécessaire.
- [ ] Death screen affiche cause correcte.
- [ ] Save screen n'écrase pas sans confirmation.
- [ ] Dialogue applique conséquences.
- [ ] Quest journal se met à jour.

## Accessibilité
- [ ] Sous-titres.
- [ ] Taille texte.
- [ ] Réduction effets.
- [ ] Contraste amélioré.
- [ ] Rebind controls.
