# Dernière Zone — Premium Asset Pipeline — Pack 03 : FPS Hands + Animations

Ce pack ajoute le début du pipeline premium pour les mains en première personne et les animations d'interaction.

## Pourquoi c'est important

Le joueur voit les mains tout le temps. Si les interactions boire, manger, bandage, porte, radio et lampe sont propres, le jeu paraît beaucoup plus professionnel.

## Contenu

- modèles OBJ de base : mains gantées, avant-bras, props tenus ;
- textures PBR 2K : gants, tissu veste, bandage, peau sale ;
- spécifications d'animations détaillées ;
- planches frame-by-frame ;
- icônes d'actions ;
- guide d'import Unity/Godot/Unreal ;
- pipeline Blender ;
- checklist qualité.

## Limite

Les modèles fournis sont des bases propres pour production. Pour un vrai niveau AAA :
- refaire un sculpt propre des mains ;
- faire retopo ;
- UV détaillés ;
- rig doigts ;
- skinning ;
- polish animation ;
- textures Substance.
