# Quality bar — FPS Hands + Animations

## Mains

- [ ] Proportions crédibles.
- [ ] Ne masquent pas trop l'écran.
- [ ] Gants usés lisibles.
- [ ] Manches cohérentes avec survivant.
- [ ] Rig doigts prévu.
- [ ] Animation idle subtile.
- [ ] Interactions lisibles.

## Animations

- [ ] Keyframes propres.
- [ ] Timing naturel.
- [ ] Pas de clipping caméra.
- [ ] Pas de clipping objet/main.
- [ ] Son synchronisé.
- [ ] Gameplay apply time défini.
- [ ] Interruptible si soin/consommation.
- [ ] Retour idle propre.

## Moteur

- [ ] Animation importable.
- [ ] Events animation configurés.
- [ ] Système d'interruption.
- [ ] Liaison avec inventaire.
- [ ] Liaison avec survival stats.
- [ ] Liaison avec audio.
