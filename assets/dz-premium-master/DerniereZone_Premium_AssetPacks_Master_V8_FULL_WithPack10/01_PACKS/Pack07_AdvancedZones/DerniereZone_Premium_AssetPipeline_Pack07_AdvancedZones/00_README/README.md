# Dernière Zone — Premium Asset Pipeline — Pack 07 : Zones avancées

Ce pack ajoute les grandes zones du jeu :
- Hôpital Saint-Mary ;
- Métro République ;
- Laboratoire Oméga ;
- Zone Militaire Nord.

## Contenu
- briefs détaillés par zone ;
- cartes/blockouts ;
- kits modulaires OBJ/MTL ;
- props spécifiques ;
- textures PBR 1K ;
- quêtes et événements ;
- placement ennemis ;
- interactions et puzzles ;
- audio/lumière ;
- data JSON ;
- guides Unity/Godot/Unreal ;
- pipeline Blender ;
- QA.

## Note qualité
Les modèles sont des modules de production/blockout propre. Pour un niveau Marketplace/AAA-like, il faut ensuite remodéliser, UV, decals, lighting pass, LODs, collisions et scènes demo moteur.
