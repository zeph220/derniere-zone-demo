# Direction artistique premium — Rue principale

## Intention

Le premier quartier doit être immédiatement lisible : une ville évacuée sous la pluie, bloquée par des débris, avec des boutiques abandonnées, vitrines cassées, lampadaires faibles et brouillard.

## Mots-clés

- pluie froide ;
- asphalte mouillé ;
- vitrines brisées ;
- enseignes mortes ;
- déchets urbains ;
- brouillard bas ;
- lampes oranges et vertes ;
- quarantaines improvisées ;
- traces de panique.

## Palette

- gris-bleu dehors ;
- jaune faible des lampadaires ;
- vert pharmacie désaturé ;
- rouge uniquement pour urgence ;
- orange pour signalisation ;
- noir humide pour asphalte.

## Règles visuelles

1. Le sol doit refléter la lumière.
2. Les vitrines cassées doivent attirer l'œil.
3. Les accès bloqués doivent sembler naturels : voitures, barrières, effondrement.
4. Les bâtiments visitables doivent être plus reconnaissables que les façades décoratives.
5. Les props urbains doivent guider le joueur sans flèches géantes.
6. Chaque rue doit avoir au moins un repère visuel fort.

## Modules clés

- route 4m ;
- trottoir ;
- bordure ;
- mur extérieur ;
- vitrine ;
- porte ;
- façade supérette ;
- façade pharmacie ;
- rideau métallique ;
- ruelle ;
- voiture détruite ;
- barricade ;
- lampadaire.

## Ce qu'il faut éviter

- rue trop large et vide ;
- lumière uniforme ;
- trop de props inutiles ;
- façades répétées sans variation ;
- accès bloqués qui ressemblent à des murs invisibles.
