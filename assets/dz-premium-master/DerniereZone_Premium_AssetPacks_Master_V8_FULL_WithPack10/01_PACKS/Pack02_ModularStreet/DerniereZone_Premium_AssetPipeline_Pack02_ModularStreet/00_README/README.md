- des props urbains ;

- textures PBR 2K ;
- briefs artiste ;
- level design blockouts ;
- guides Unity/Godot/Unreal ;
- script Blender ;
- checklist qualité.

## Important

Les modèles OBJ sont des bases de production détaillées/low-poly, pas des modèles AAA finaux sculptés. Ils donnent les proportions, les pivots, les catégories et la cohérence visuelle. Pour atteindre un vrai niveau Marketplace premium :
1. retravailler dans Blender ;
2. UV propres ;
3. high-poly/low-poly si nécessaire ;
4. baking normal/AO ;
5. texturing Substance ;
6. LOD/collisions ;
7. intégration moteur.
