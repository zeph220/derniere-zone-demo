# Blockout quartier de départ

## Structure

```
[Route bloquée nord]
       |
[Pharmacie] -- rue principale -- [Supérette]
       |             |              |
    ruelle       voitures        ruelle arrière
       |             |              |
    [Garage] ---- [Abri] ---- [Sortie bloquée]
```

## Rythme

1. Le joueur sort de l'abri.
2. Il voit la rue principale.
3. Supérette visible à droite : nourriture/eau.
4. Pharmacie visible à gauche : soins, porte verrouillée.
5. Garage plus loin : outil, câble, danger.
6. Route bloquée par voiture + barricade.
7. Ruelle donne un secret ou raccourci.

## Distances

- Abri à supérette : 20-30 m.
- Abri à pharmacie : 25-35 m.
- Abri à garage : 40-55 m.
- Largeur route : 7-8 m.
- Trottoirs : 1.5-2 m.
- Ruelle : 2-3 m.

## Repères

- Enseigne pharmacie verte.
- Enseigne supérette éteinte.
- Lampadaire clignotant.
- Voiture retournée.
- Panneau quarantaine.
- Brouillard en fond de rue.

## Gameplay

- Première exploration sans combat obligatoire.
- Un ennemi normal peut apparaître près du garage.
- Supérette contient première pile.
- Garage contient câble/pied-de-biche.
- Pharmacie contient dilemme médical plus tard.
