# Pipeline Blender — Props / Items

## Étapes
1. Importer les OBJ.
2. Ajuster proportions.
3. Ajouter bevels et détails.
4. UV propre.
5. Textures PBR/Substance.
6. Créer version monde + version inventaire si nécessaire.
7. Créer collisions simples.
8. Export GLB/FBX.
9. Tester en vue FPS.
