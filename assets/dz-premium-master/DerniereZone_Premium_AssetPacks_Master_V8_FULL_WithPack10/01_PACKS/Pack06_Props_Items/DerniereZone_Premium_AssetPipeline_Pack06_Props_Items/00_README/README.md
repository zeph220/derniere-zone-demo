- 25 objets gameplay.
- Modèles OBJ/MTL.
- Textures PBR procédurales 1K.
- Icônes d'inventaire/craft.
- Fichiers JSON items/craft.
- Specs d'animations d'utilisation.
- Guide inventaire/craft.
- Guide Unity/Godot/Unreal.

- QA checklist.
- Previews.

## Objectif

- inventaire ;
- craft ;
- interactions ;
- animations FPS ;
- quêtes ;
- UI ;

## Note qualité
Les modèles sont des bases propres de production. Pour un vrai niveau Marketplace, les props héros doivent être repris dans Blender/Substance avec UV, bevels, détails, LODs et collisions.
