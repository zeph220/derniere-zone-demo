# Factions

## Les Secouristes
- Leader : Capitaine Moreau
- Base : Camp médical près de l’hôpital
- Idéologie : Sauver les civils avant tout.
- Visuel : blanc sale, orange, croix médicales, tentes
- Audio : radio claire, générateurs faibles
- Récompenses : soins, renforts finaux, réduction troc médical
- Risques : demandent des ressources, faibles militairement
- Fin : reconstruction_humaine

## Les Pillards
- Leader : Rask
- Base : Ancien dépôt logistique
- Idéologie : La force protège les vivants.
- Visuel : rouge sombre, tags, ferraille
- Audio : cris, percussions métalliques
- Récompenses : armes, munitions, accès dépôt
- Risques : violents, bloque d’autres alliances
- Fin : ordre_brule

## Cellule Oméga
- Leader : Dr Eva Renaud
- Base : Laboratoire Oméga
- Idéologie : La recherche peut sauver ou condamner.
- Visuel : bleu froid, verre, néons
- Audio : bips, ventilation, voix filtrées
- Récompenses : accès labo, technologie, vérité
- Risques : mensonges, sacrifices passés
- Fin : controle_scientifique

## Habitants Cachés
- Leader : Léa
- Base : Sous-sols et tunnels
- Idéologie : Rester invisibles.
- Visuel : vert sombre, bougies, cartes manuelles
- Audio : murmures, gouttes, silence
- Récompenses : raccourcis, refuges, informations
- Risques : paranoïa, ressources faibles
- Fin : exode_souterrain

## Les Sentinelles
- Leader : Colonel Keller
- Base : Zone militaire Nord
- Idéologie : Maintenir la quarantaine à tout prix.
- Visuel : kaki, gris, projecteurs, barbelés
- Audio : haut-parleurs, alarmes, métal
- Récompenses : équipement lourd, protection, accès zone militaire
- Risques : autoritarisme, ville verrouillée
- Fin : quarantaine_totale
