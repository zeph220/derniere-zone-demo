# Carte et level design

```text
[Zone Militaire Nord] ---- route bloquée ---- [Centre-ville]
        |                                      |
   [Garage] ---- [Quartier de départ] ---- [Hôpital]
        |              |                       |
   [Supérette]     [Abri]                [Métro République]
                                           |
                                  [Laboratoire Oméga]
```

## Supérette
Entrée vitrée → Rayons → Caisse → Réserve verrouillée → Sortie arrière. Loot : eau, nourriture, pile, note.

## Pharmacie
Entrée → Comptoir → Rayons → Bureau → Arrière-boutique. Loot : bandages, antibiotiques, note médicale.

## Garage
Entrée large → Atelier → Fosse → Bureau → Réserve → Porte arrière. Loot : pied-de-biche, câble, fusible, métal.

## Hôpital
Accueil → Urgences → Chambres → Pharmacie interne → Bloc opératoire → Sous-sol.

## Métro
Entrée → Billetterie → Tourniquets → Quais → Train abandonné → Tunnels → Locaux techniques.

## Laboratoire
Sas → Recherche → Observation → Cellules → Serveurs → Salle Hélios.

## Zone militaire
Checkpoint → Cour véhicules → Baraquements → Armurerie → Commandement → Bunker.
