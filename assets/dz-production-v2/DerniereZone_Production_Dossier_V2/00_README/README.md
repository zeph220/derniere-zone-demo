# Dernière Zone — Production Dossier V2

Dossier complet pour guider Codex/Unity/Godot/Blender : systèmes, données, icônes, textures, modèles 3D placeholder, animations et QA.

## Limite honnête
Les modèles 3D sont des blockouts low-poly propres pour commencer, pas des assets AAA finaux. Les textures sont procédurales et suffisantes pour prototyper. Les animations sont des spécifications exploitables pour créer les vrais clips.

## Priorité
1. IA ennemie lisible.
2. Interaction + inventaire + quêtes + sauvegarde.
3. Survie complète.
4. UI complète.
5. Audio dynamique.
6. Modèles/animations remplacés progressivement.
