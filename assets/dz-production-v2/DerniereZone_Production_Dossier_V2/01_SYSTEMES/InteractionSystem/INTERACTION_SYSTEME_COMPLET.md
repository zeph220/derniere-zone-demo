# Interaction System

## Types
Ramasser, lire, utiliser, ouvrir, déverrouiller, parler, fouiller, réparer, placer, transition.

## Priorité
Objectif de quête actif > objet regardé > objet proche > interaction critique.

## Feedback
Prompt court, son, icône, message d’échec clair : clé nécessaire, outil requis, courant coupé.

## Interactions longues
Bandage, réparation, fouille profonde, barricade. Elles sont interruptibles par dégâts ou mouvement.
